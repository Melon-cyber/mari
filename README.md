# Мари

Читалка статей «на потом» для Android. Без рекламы, без аккаунтов и без серверов: статьи сохраняются только на телефоне.

## Возможности

- Сохранение через «Поделиться» из браузера, Telegram и других приложений или вставкой ссылки (ссылка из буфера подставляется сама).
- Режим чтения: из страницы остаётся только текст статьи с заголовками, картинками, списками и цитатами, без меню, рекламы и комментариев.
- Сохранённые статьи читаются без интернета.
- Оформление: размер текста, шрифт с засечками или без, межстрочный интервал, тёмная, сепия или светлая тема.
- Мари помнит, где ты остановился, и показывает, сколько прочитано.
- Чтение вслух голосом телефона: текущий абзац подсвечивается, страница листается сама, скорость от 0,8× до 2×.
- Полки «Читать», «Избранное», «Прочитано» и поиск. Удалённую статью можно вернуть.

## Сборка

Нужны JDK 17+ и Android SDK 36. `./gradlew :app:assembleRelease`. Подпись настраивается файлом `keystore.properties` (не попадает в Git); без него используется стандартный отладочный ключ.
